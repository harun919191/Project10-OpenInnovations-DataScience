# Rights and reuse

No blanket open-source licence is granted for the original coursework code or newly written documentation in this staging package. Public inspection is proposed; a permissive reuse licence has not been selected by the author. Retaining this position permits a source-available portfolio without asserting ownership over third-party work.

Third-party components retain their own licences, copyright notices and conditions, listed in THIRD_PARTY_NOTICES.md and accompanying licence files. This notice does not restrict permissions already granted by those upstream licences.

Recommendation: select a code-only permissive licence only after the author confirms authority over those files. Dataset and model terms must remain separate. No licence is inferred from academic assessment completion.
